# TetherLock 视觉体系

App 与 simulator 共用温润、精致的消费级视觉。App 以设备状态和控制为主，simulator 以三维模型与调试为主。浅色与深色主题都使用语义色，连接状态和锁状态分别展示。

Flutter 的源定义位于 `apps/controller/lib/src/ui/theme.dart`，simulator 对应 `apps/simulator/src/tokens.css`。更新视觉规范时需同时修改两端。

间距使用 4、8、12、16、24、32 px；面板圆角 16 px，按钮和输入框圆角 10 px。页面标题 28 px，分组标题 18 px，正文 14–16 px，辅助信息 12 px，倒计时 40 px。数值采用等宽数字，技术标识使用等宽字体。字体使用平台字体及中文回退，运行时不请求字体服务。

操作目标至少 48 px。状态使用文字及图标，不依赖颜色辨认。危险操作使用独立区域和确认交互；不可用操作显示具体原因。键盘焦点可见，支持文字缩放与减少动画偏好。

## App

导航统一为设备、密钥、连接、记录。连接页包含 MQTT 配置。

| 宽度 | 导航 | 设备工作区 |
| --- | --- | --- |
| < 800 px | 底部导航 | 列表进入详情，提供返回按钮 |
| 800–1099 px | 侧边导航 | 列表进入详情，提供返回按钮 |
| ≥ 1100 px | 侧边导航 | 280 px 列表与控制详情双栏 |

控制详情突出锁状态、剩余时间、更新时间和盖板 / 插销 / 紧急卡指标。常用操作随设备状态调整；固件、校时、截止时间和身份信息收纳到设备详情。紧急开锁独立呈现并保留确认。发送命令后仍等待设备报告最终结果。

密钥、连接、操作记录共用页面标题、卡片、空状态与表单。小于 600 px 的表单使用全屏对话框；其他宽度使用限宽、可滚动对话框。

顶栏「外观主题」提供跟随系统、浅色、深色。偏好写入已有本地快照的可选字段 `theme_preference`；旧快照与未知值默认跟随系统，快照版本和协议保持兼容。

## Simulator

1000 px 起使用三维视口与检查面板，默认约 60:40，保留可拖动、可键盘调整的分隔线；更窄窗口改为上下布局。

模型区顶部放相机、适配视图、透明外壳及重载工具，下方放盖板操作和实体按钮。三维背景跟随主题，CAD 配色、物理运动和传感器标识沿用既有定义。

三维视口采用本地生成的摄影棚环境反射、主光 / 补光 / 轮廓光、ACES 色调映射和地面阴影。塑料、金属与透明亚克力使用不同的粗糙度和反射参数；曲面平滑，结构转角保留细轮廓。OLED 显示不参与色调映射，保证文字对比度。

相机预设和「适配视图」根据当前盖板姿态与窗口比例取景；手动拖动后保留用户视角。静止时跳过重复绘制，阴影仅在运动或透明模式改变时更新。最新效果见 [三维渲染验收](validation/simulator-rendering/README.md)。

右侧页签为概览、调试、连接、日志。状态与时间控制位于概览，故障与传感器输入位于调试，重置设备位于调试页底部。页签支持方向键、Home、End，切换保留输入草稿。实体按钮在释放、取消、失焦、页面隐藏及窗口关闭时释放。

主题偏好保存到 `tetherlock.theme`，相机仍使用原有 `tetherlock.camera`。跟随系统模式响应系统主题变化；存储失败显示提示。日志继续保留最近 1000 条并使用虚拟滚动。
