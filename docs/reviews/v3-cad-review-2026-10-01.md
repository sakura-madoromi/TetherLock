# V3 CAD 独立复核与交付检查

日期：2026-10-01。复核范围为当前六个 `hardware/v3/cad/*.scad`，不是旧提案的共轴局部模型。独立审查由只读审查代理完成，主作者对提出的问题修复后重新导出验证。

## 已发现并修复

| 问题 | 当前修复 |
|---|---|
| 共轴空心栓先把外力传到丝杠 | 丝杠偏置，6 mm实心栓由键轨、导向盖及前端承窝支承；拨指留浮动空间 |
| 锁扣底部插入底座，开盖扫到前承窝 | 锁扣底面抬至32.6；承窝入口移到14.8；14 mm行程及较长栓舌维持闭锁支承 |
| 后梁挡住盖板旋转 | 后梁上沿改轴心圆弧；销轴护罩外形同步避让 |
| 铰链孔不连续，销轴难以贯穿 | 一条连续Ø2.4孔；180 mm销轴覆盖两个轴环 |
| 轴环未锁紧 | 标准M2×2紧定螺钉及内侧护罩；护罩局部凹槽留0.3 mm顶隙 |
| OLED压条边孔切出碎片 | 扩大压条与内侧座、调整孔位置；单连通网格通过 |
| 电机前肩顶桥挡住垂直放入 | 顶部开放U槽；新添整个预装驱动组件的垂直放入检查 |
| 电机、按键、磁铁与电子件固定不足 | 电机垫片/压板、按键后板、磁铁胶粘、检测板和PCB胶垫、压条/绑带进入装配说明 |
| 板夹柱、螺钉头、接头与周边干涉 | 改夹柱/板位置、局部头部凹槽、接头包络及托盘避空；实际实体相交重检 |

## 复核结果

主验证 [verification.json](../../generated/v3/verification.json)：**1,034项，0失败**。21种打印STL有正体积、封闭边、单连通表面且Z=0落床。闭合含硬件总装测得240×120×55；全总装STL用于包络检查，其接触/攻牙布尔网格不作为单件打印文件。

独立审查另从与工作区hash相同的六文件快照导出，将全部移动驱动件与移动螺钉合组，检查其与静止件/固定螺钉的实体交集。在0.5、1.5、3、5、9、10、11、12、13、13.5 mm均为空。已保留 [复现模型](v3-cad-evidence/travel-probe.scad)、[复跑脚本](../../scripts/v3/verify_review.py) 和 [10项通过结果](../../generated/v3/review-verification.json)。

独立复核未发现新的明确CAD阻塞问题。特别核对闭锁完整栓截面支承3.4 mm、退栓尖端距锁扣1 mm；开盖、安装和电池维护姿态的检查见主验证数据。两套结果均记录源hash，可对照实际交付文件。

## 交付边界

审查要求保留的打印事项已列入 [结构说明](../design/v3-cad.md)：栓舌平放后13.5 mm悬出段需支撑；螺母滑块拨指和铰链护罩也需支撑；电池顶板约22 mm桥跨须首件验证。

运动检查是离散采样；不能代替连续扫掠证明或公差分析。硬件型号仍待采购实测，板胶垫/胶粘保持力、打印装配、轴向承载、锁扣断裂力、机械自锁、低电压带载≤15秒开锁尚需实物验收。固件与电路适配不在本次CAD交付内。
