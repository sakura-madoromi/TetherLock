# 现购物料适配复核

用户尺寸图：按钮 bw1v2lpe.webp；N20电机 xv97n9y4.webp。当前规格、参数含义和未完成接口详见[现购物料适配版](../design/v3-purchased-specs.md)。

复核中实际发现并修正：

- 偏置电机本体与旧压板高度不匹配：提高本体座和压板，同时保留丝杆轴高。
- 加大的M4螺母盖/座在闭锁末端碰到锁扣压板螺钉头：缩小右侧外轮廓并调整螺钉位置。
- 侧壁按钮凹入座碰到驱动板固定螺钉：移位，保留螺钉与端子服务空间。
- 绑带槽只改宽后仍受托盘侧挡边遮挡：切通高度，并用2.5mm实体量规重新验证。

当前实体导出与七组验证合计1148项通过，报告均包含当前CAD源文件指纹。另生成固定蓝图与物料数据审计；没有用历史霍尔测试通过记录证明新机械反馈有效。

限制：按钮螺纹/螺母和M4配套法兰螺母尺寸仍未给全；机械到位开关/触发支架待选型，当前仅人工电气台架。实际板件排针、保护板、线束、触发/释放、打印保持力和带载≤15秒仍需实物验收。
