# V3 生成资料与规范交付包

`generated/v3/` 保存本机当前验证输出、临时网格、蓝图、渲染和打包结果，不纳入 Git。参数模型位于 `hardware/v3/cad/`，工程主表位于 `hardware/v3/engineering/`。

明确交付的三个规范包使用 LFS 保存：

- [CAD 与打印件](../../assets/deliverables/v3/TetherLock-V3-CAD.zip)
- [蓝图与工程资料](../../assets/deliverables/v3/TetherLock-V3-Blueprints.zip)
- [静态 Web 工作台](../../assets/deliverables/v3/TetherLock-V3-Workbench.zip)

这些资料只证明部分名义几何和数字检查结果，不替代实物试装、强度与耐久测试、电气、固件或安全验收。项目仍处于未完工状态。

完整更新、交付验收和资源晋升流程见 [Git/LFS 维护说明](../maintenance/repository.md)。修改前快照保留在本地备份；历史证据不伪装为当前通过。
