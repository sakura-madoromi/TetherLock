## 外购件与百元预算

[BOM](v3-bom.csv) 的金额是**预算分配，不是商家报价**。当前整机分配合计100元，独立充电器另留15元；自有充电器可省掉这一项。打印费用按自有打印机的耗材估算，外包打印工时另计。能否落在约百元，待你后续核实实物价格与型号。

`hardware.scad` 对电机、OLED、开发板、电源/驱动板、三处检测元件、电池座、接头、磁铁、销轴、铜螺母和全部紧固件建了尺寸包络。采购前应逐项核对：常见的大霍尔模块、加长保护18650或不同厚度OLED不能直接当作模型里的小包络。先定实际SKU，再改CAD接口。

电机垫片名义压缩厚度0.3 mm；PCB底部双面胶垫为ESP/电源板0.9 mm、驱动板0.5 mm；两块栓位检测板底胶垫0.4 mm、闭盖检测底垫0.5 mm。胶垫负责定位，板上压条/绑带负责防脱，实际PCB底面与元件须适配胶垫。磁铁用少量环氧固定，避免挤入运动间隙。

螺钉模型仅给出杆、头和孔的包络，未建螺纹；Ø1.7/Ø2.4为塑料试样导孔。电池盖4处、内栅4处、铰链端盖2处改为M2铜螺母；其它塑料直接攻牙连接的保持力、复拆次数和实物头径需确认。详见[v3-hinge-hall.md](v3-hinge-hall.md)。

## 打印与装配

单件底壳的落床包络为240×120 mm。使用带裙边时建议有效打印区域至少250×130 mm；常见220×220平台不能直接打印本版整件外壳。分拆壳体需要另外设计连接接口。

| 分件 | 数量 | STL姿态与打印注意 |
|---|---:|---|
| `base_box` / `lid` | 各1 | 底壳底面向下；盖外面向下。电池顶板约22 mm桥跨、铰链、显示窗和盖内承座需局部支撑或经首件验证的桥接设置 |
| `lock_base` | 1 | 底板向下；承窝6.8 mm横孔、U槽边缘检查桥接与孔形 |
| `bolt` | 1 | 长轴平放；细舌底比主体高1.6 mm，13.5 mm悬出段必须设支撑；叉口及底键槽也需切片检查 |
| `nut_carriage` | 1 | 底面向下；侧拨指为悬臂，需要支撑，清理后试配 |
| `latch` | 1 | 已转到5 mm厚度平放，T形轮廓与颈部在层面内；另外打印备用件 |
| `hinge_guard_left/right` | 各1 | 两只不同的限位端盖，底脚落床，检查顶罩支撑；同外壳耗材。 |
| `insert_coupon` / `keeper_insert_coupon` / `window_insert_coupon` / `hinge_bore_coupon` | 各1，可选 | 铜螺母预孔2.8/2.9/3.0；横向钢销孔2.2/2.4/2.6，先试配。 |
| `hall_sensor_coupon` / `hall_magnet_coupon` / `hall_gap_gauge` | 各1，可选 | 霍尔台架试件和0.5/1/2/4mm梳状间隙量规；尺寸须卡尺测量。 |
| `window_grille` | 1 | 内表面落床、沉头口朝下；与外壳同耗材同色；顶盖外栅随盖外面朝下打印 |
| 其余盖、压条、维护盖和托盘 | 各1 | 已落到Z=0；检查台阶/悬臂，按需要局部支撑 |
| `fit_bar` / `fit_gauge` | 各1，可选 | 先测6 mm栓与6.4/6.6/6.8 mm孔；以实测打印误差调整间隙 |

按普通0.4喷嘴先用0.2层高试样。机构件优先较多壁线和局部实心；壳体按切片结果选择填充。支撑面、象脚与孔口去毛刺后再测配合。这里没有免支撑或强度认证。

建议装配顺序：

1. 打印配合试块，选定电机、螺母、电池座和电子板的实际尺寸；切片确认支撑能从电池底开口清出。
2. 独立组装锁驱动：从上方放入螺母，安装螺母盖；旋转丝杠使滑块到退栓位；在模块外将拨指与锁栓叉口结合，磁铁粘牢。
3. 检测板贴入底座槽，安装锁模块底座；把电机、滑块、锁栓整体从顶部下放，键轨进入底槽，最后装电机压板、定位垫和导向盖。
4. 电子底托装胶垫、ESP和电源板，固定压条及绑带；上层托板装驱动板胶垫和压条。先留好导线长度，再将托盘固定到盒体。
5. OLED从上方滑到两侧轨槽和下挡台，装顶部压条；按键贴住内壁后装后压板，引线经过板上孔。
6. 主盖外面朝下，依次放无孔窗片和阶梯内栅，不使用窗垫；四颗M2×6沉头螺钉均匀轻拧，使四耳贴住硬限位。检查窗片无晃动、无明显弯曲。T头锁扣由内侧压板捕获，插入销轴，安装左右打印限位端盖；十处铜螺母预先在测试块确认工艺后热装。
7. 底部接好电池座插头，放入电池座，装维护盖。电池盖的4块凸垫支承并限位电池座。
8. 手动检查全行程和开盖、取物；接线后测试位置传感、失电状态、低电压开锁。旧MG90S控制固件须适配N20及位置反馈后再整机使用。

主盖闭锁时可从底部拆维护盖、取出电池座并断开接头，再取出电芯放入独立充电器。隔墙和顶板将电池维护口与驱动机构隔开；这未经过工具探入或防撬实测。断电保持锁态和状态恢复依赖机械自锁及固件持久化，需要共同验证。

- 29种打印STL：正体积、封闭边、单连通表面、最低点Z=0。
- 带硬件和螺钉的闭合总装：包络恰为240×120×55；总装布尔STL含接触/攻牙，**不作为单件打印网格**。
- 退栓、中间7 mm和闭锁14 mm：按真实STL包围盒筛选后，检查各独立零件的实际实体交集。
- 锁行程0/2/4/6/8/14 mm；锁栓X/Z正负0.25 mm偏移；导向0.35 mm接触负对照。
- 螺钉只排除其明确配合零件中的攻牙交集；其余实体干涉仍检查。4 mm直杆工具从主盖开105°位置接近主要机构螺钉。
- 开盖0～105°每1°，另加0.25/0.5°：检查壳体、机构、电子件、紧固件、销轴及护罩。
- 储物块沿Z取出、电池座向下取出、螺母上方装入、驱动组件向下装入均按列出的多个姿态检查。
- 闭锁后开盖1°必须发生干涉；异常姿态负对照用于确认检查器会报告碰撞。

整机开盖/驱动运动检查为离散采样；组装页钢销、端盖和内栅维护路径另有六段连续Minkowski平移扫掠证据。尚未做整机连续扫掠证明、FDM公差叠加、线缆柔性分析或力学仿真。实物验收至少覆盖连续手动开盖、首次装配与清支撑、带载锁栓摩擦、电机轴向承载、跌落后检测可靠性，以及锁扣断裂行为。

14 mm行程 / 0.5 mm牙距=28圈。理想机械时间 `1680/rpm` 秒；低电压带载140 rpm约12秒，剩余约3秒留给唤醒、控制及确认。**≤15秒要求还未通过实物测试**；联网等待如何计时须在控制设计中明确。若低电量、锁栓受力、误报或堵转时达不到要求，需要调整电机、供电或控制；不能用空载转速代替验收。
