## 到货后优先测量

记录单位统一用 mm。每个模块同时记录 PCB 尺寸和安装后的总包络，包含排针、焊点、插头、端子、螺母及出线。拍正面、背面、侧面和接口标识照片，附尺或卡尺读数。

- [ ] **电机配套法兰螺母（优先）**：形状是六角还是圆形多孔；六角对边、法兰外径、总厚、法兰厚、凸台直径；如有安装孔，记录孔径、孔数和孔距；确认螺纹。当前候选为 AF7、法兰 Ø10、总厚 5、法兰厚 1，实物不符需重做螺母座/盖。
- [ ] **N20 电机**：电机与齿轮箱各自长度、总长、宽高；输出轴偏置及方向；丝杆外伸长度、直径、轴根台阶；端子和出线占用空间。当前本体候选 25×12×10，轴偏置 2.5，丝杆外伸 55±1。
- [ ] **R16-503 按钮**：螺纹外径、有效螺纹长度、螺母外径和厚度；法兰直径、面板后本体和端子长度、面板外突出量；按压行程；确认两脚常开、松手复位。当前孔径 Ø16.4 为候选；需确认能夹持 3mm 面板并留出焊线空间。
- [ ] **ESP32-C3 SuperMini**：PCB 长宽厚、两面最高元件/排针突出量、排针间距、USB 接口位置及插线占用空间；记录实际引脚标识。
- [ ] **DRV8833 模块**：PCB 与总包络、安装孔/排针坐标、端子和出线；拍芯片型号和板上标识，核对是否引出 STBY/nSLEEP、故障脚及默认状态，不沿用其他厂商板的引脚假设。
- [ ] **TPS63020 3.3V 模块**：PCB 与总包络、输入输出焊盘位置、安装孔、出线；确认实际输出设定和使能脚标识。
- [ ] **0.96 英寸 OLED**：PCB、玻璃及可视区尺寸和相对位置；四脚排针位置、高度和顺序；确认控制器、I²C 地址与供电要求。
- [ ] **1S 保护板**：含镍片/焊线的总尺寸、芯片标识、B+/B−/P+/P− 对应位置；核对卖家资料中的电池类型、保护阈值和电流能力。不要仅凭“4012A”名称套用其他板参数。
- [ ] **18650 电池座**：装入电池后的总长宽高、接点/出线位置、固定方式、取出电池所需空间和极性。
- [ ] **SM 2P 接头**：插合后的长宽高、锁扣突出量、拔插空间、导线外径和弯曲空间。
- [ ] **电机去耦电容（选定后）**：外径、高度、引脚间距，包含弯脚和绝缘后的安装包络。
- [ ] **2.5mm 绑带**：实际宽度、厚度、锁头长宽高；用试块确认 3mm 槽可穿过，并确认锁头不会顶到板件或外壳。

## 紧固件与机械件后续采购时检查

- [ ] 连续 Ø2 圆棒：实际直径、直线度；截取 180mm 后去毛刺，验证铰链试块。短轴不胶粘拼接。
- [ ] 热熔螺母与螺钉：实测螺母外径/长度、螺钉头尺寸和有效长度，用试块确定孔径；不同卖家规格不能仅凭 M3 名称互换。
- [ ] 如继续开发自动到位检测，选定实际机械开关后记录外形、安装孔、触发力、动作位置及允许超行程，再设计支架和触发件。当前没有完成的机械开关安装方案。

## 电气台架验证

- [ ] USB 供电下验证主控、屏幕和按钮；核对实际板的引脚，记录结果。
- [ ] 用限流电源给电机单独提供 3V，与主控共地，验证正反转、启动电流、带载电流和完整 14mm 行程时间；电机电流不走面包板。
- [ ] 核对驱动与电源模块的实际芯片封装、温升及供电能力；型号名称不能代替整板测试。

- [ ] 在机械到位检测及其可靠性验证完成前，保持人工台架测试，不按自动闭锁整机验收。
