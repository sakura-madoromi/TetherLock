# V3 铰链端盖、维护螺纹与合盖检测核验

本次改版保留240×120×55 mm及185×95×40 mm验收空间。使用Ø2×180mm钢销；删除两个独立轴环和两颗M2×2紧定螺钉。

## 铰链与拆装

底壳/顶盖交错轴套仍绕同一条X向轴线转动，轴套孔Ø2.4。两只打印端盖的实体端壁挡住销两端：左挡面X=-107.5，右挡面X=73.5，钢销X=-107～73，名义各0.5mm轴向间隙。端壁名义厚1.5mm，外轮廓限制在后梁轴心周围，避免阻挡盖子转动。固定点X=-108/77.5、Y=-50.5；端盖顶面≤55。脚部后缘Y=-53.6，钢销向前达到名义径向游隙0.2mm时仍有0.2mm余隙。

开盖并退栓后，卸下端盖两颗M2×6沉头螺钉。端盖先沿+Y（向盒前方）滑出约10mm，再向上取下；不要直接向上硬拔，开启的顶盖会覆盖后梁上方。两只端盖均取下后，钢销可沿X方向抽出。左右端盖不同，分别打印`hinge_guard_left/right.stl`，不要将同一件打印两次。

两颗端盖螺钉、四颗电池维护盖螺钉和四颗内栅栏螺钉改为拧入M2热熔铜螺母，共10枚。原型包络选M2、外Ø3.2、长4mm；这是采购尺寸要求，替代件外径/长度不同须调整。参考[厂家M2×4产品及CAD](https://www.ruthex.de/collections/gewindeeinsatze/products/ruthex-gewindeeinsatz-m2-70-stuck-rx-m2x4-messing-gewindebuchsen)。具体外径须以采购实物复核，不把M2内螺纹规格当作外径。

打印STL中的预孔为Ø2.9，先用`insert_coupon.stl`的2.8/2.9/3.0三孔选择实测配合；装配CAD显示热装后塑料让出的Ø3.25名义孔与Ø3.2铜螺母，两种状态明确区分。窗片承座仍有四处硬限位；不要通过加大拧紧力让窗片弯曲。螺母有效啮合长度为端盖约3.2、内栅约3.5、电池盖4mm。窗螺母上方名义留1.1mm实体顶面。

## 霍尔检查结论

固定小板包络6×6×1.8，X=74.5～80.5、Y=24～30、Z=46～47.8。底部0.5mm定位胶垫，三边挡边限制平移，+X一侧供导线/维修。顶盖磁铁Ø3×2，中心X=77.5、Y=27，下表面Z=48.6，闭盖名义封装间隙0.8mm。开盖时磁铁随顶盖转走。磁铁轴向充磁，板上敏感轴朝向磁铁；封装顶部到内部感应点的距离还须核对。

**重要发现：霍尔接近信号不能直接等同于锁扣对准。** 实际锁舌扫掠截面检查：0～0.3°样本无干涉，0.4°样本已干涉。前缘距轴约115mm，0.3°约相当于增加0.60mm盖缝；这里尚未叠加打印误差。普通高灵敏霍尔容易在更大的盖缝下触发。升级铜螺母、通过几何检查，也不能消除这个电气判定问题。

候选使用[TI DRV5032ZEDBZR数据表](https://www.ti.com/lit/ds/symlink/drv5032.pdf)中的ZE版本：3.3V在1.65～5.5V工作范围内；全极性、非锁存、开漏输出，检测到磁铁为低，移走磁铁回到高阻。输出用10kΩ上拉到3.3V，VCC附近0.1µF去耦。它比普通高灵敏版本要求更近的磁铁，但仍须测实物阈值；不可将ZE/FA/FB/FC等后缀视为互换。板上芯片、胶垫和磁铁型号尚未采购，6mm小板是需要实物确认的包络，不是现成大模块通用接口。

ZE的触发BOP为33～63mT，释放BRP为30～58mT，采样周期27～75ms；固件应考虑采样延迟及信号稳定时间。现在无法得出“0.8mm必触发、0.4°必释放”的结论。没有实测磁场和信号，霍尔电气结论是**候选兼容、待样机验证**，不是整机合盖检测已通过。

## 新手台架步骤

1. 先打印`insert_coupon`、`keeper_insert_coupon`、`window_insert_coupon`和`hinge_bore_coupon`；铜螺母试孔从左到右2.8/2.9/3.0，横向销孔从Y小到大2.2/2.4/2.6mm。用同材料、同层高及同摆放方向试配。销应能手推穿过，不能靠锤击；铜螺母要热装，不能冷压硬塞。随后用与实际8×6.5×4.8mm端盖座、18×7×5.1mm窗承座一致的两个试块检查变形/开裂；窗座试块的打印文件已翻面，与顶盖的外表面落床方向一致；端盖座装配态最小名义侧壁1.375mm，窗承座顶部剩1.1mm，重点检查热装深度。温度按耗材/嵌件建议从低到高试，保持轴线垂直，冷却后再拧螺钉。
2. 打印`hall_sensor_coupon`、`hall_magnet_coupon`、`hall_gap_gauge`。传感器放小挡框内；磁铁以其目标露出/凹入位置固定在另一块试件里。梳状量规四片名义厚度0.5/1/2/4mm，只用来辅助定位，实际间隙须卡尺测量。胶垫、芯片顶面和磁铁凹入量不相同，不能把两个塑料块之间的距离直接当成感应距离。
3. 将候选小板接3.3V/GND/独立GPIO。参照台架草图`hardware/v3/bench/hall_logger/hall_logger.ino`；默认GPIO4只作占位，接线前确认实际ESP32-C3板上此脚可用且未接其它外设。草图只记录原始电平和100ms稳定状态，不驱动电机。不要给GPIO上拉到5V。
4. 未放磁铁时应为高；闭盖目标位置应为低。分别从远到近、从近到远测触发/释放点，每次停留至少250ms。检查两种磁极方向、供电上下限、x/y偏移约±0.3mm、实际胶垫厚度；保存`hardware/v3/bench/hall-measurements-template.csv`。
5. 装上机构但保持电机断电，退栓后从闭盖基线逐步增加前缘盖缝：用0.5/1/2/4mm量规并在首次阻滞附近增加测量点，记录实际最小锁栓阻滞缝隙。分别在合盖和开盖方向测量霍尔触发/释放，要求信号报合盖的范围始终小于锁栓可无阻通过的范围，并留出实測余量。原型目标是在基线上增加0.5mm盖缝前就释放，最终按样机的实际阻滞边界和误差调整；只在完全打开和完全合上测两点不算通过。若锁栓不能无阻通过而霍尔仍报合盖，该配置不合格。不能通过增加电机力解决。先调整传感器/磁铁位置或降低磁铁强度，重复验证；若无法稳定分辨，应增加机械到位检测或采用经过校准的连续位移检测。
6. 合格样机至少重复开合100次，闭盖状态不漏检，开盖状态不误报；在电机通电、安装手机及移动线束后再复验。锁紧必须同时具备可靠的盖到位条件和闭锁到位反馈；断线的高电平只会阻止锁紧，但不能区分“开盖”与“线断”。新V3控制固件尚未实现，这里的台架草图不能作为锁控制程序。

## 可复现证据

运行`python3 scripts/v3/verify_hinge_hall.py`生成`generated/v3/hinge-hall/verification.json`与磁铁运动位置表。涵盖两端止挡、额定销间隙、端盖滑出路径、钢销抽出路径、螺母/硬件非配合干涉、工具通道、封装间隙及锁舌对准边界。整机其它相交/开盖检查由`export_verify.py`生成。验证的是名义几何和离散采样，打印强度、实际孔径、胶粘保持力、磁触发及≤15s带载开锁仍需实测。
