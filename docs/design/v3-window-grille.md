# V3 无窗垫双层防护栅窗

外栅随顶盖整件打印，可拆内栅与外壳同色、同耗材。开口145×78 mm，五根宽5 mm的栅条沿短边跨接，根部R2；亚克力保持149×82×1.5 mm，无钻孔，横向名义间隙每侧1 mm。

| 部位 | 名义闭合坐标（mm） |
| --- | --- |
| 外栅与窗口边框 | Z=52～55 |
| 亚克力 | Z=50.5～52，厚1.5 |
| 内栅接触边框及栅条 | Z=47.4～50.5，厚3.1 |
| 内栅四个固定耳 | Z=47.4～49.9，厚2.5 |
| 盖内耳限位面 | Z=49.9 |
| 四枚M2铜螺母 | Z=49.9～53.9，外径3.2、长4 |

`window_inner_t` 控制接触部分，`window_ear_t` 控制固定耳，两者独立。四颗M2×6沉头螺钉从盒内向外安装，杆端Z=53.4，铜螺母名义啮合长度3.5 mm，距顶面1.6 mm；铜螺母顶面余料1.1 mm。打印预孔Ø2.9为试样起点，装配铜螺母包络为Ø3.25；不是直接打印金属螺纹。

固定耳与盖内限位面承担螺钉预紧力，窗片通过直接接触捕获；亚克力弹性不作为夹紧补偿。最低内栅Z=47.4，距储物验收包络顶面Z=45留2.4 mm。

装配与试样检查：

1. 清除内外栅接触面的毛刺、支撑残留和凸点。
2. 测量实际亚克力板厚并记录；板边去毛刺、倒钝尖角。
3. 主盖外面朝下，先放亚克力，再放内栅。
4. 四颗螺钉交叉、均匀轻拧至固定耳贴住限位面。
5. 检查窗片晃动、翘曲和局部顶压。若板厚或平整度不合适，调整 `window_inner_t` 后重打内栅；不得继续拧紧强迫窗片弯曲。

电机定位垫、PCB绝缘胶垫、霍尔定位胶垫仍保留。当前版不含窗垫实体、采购行或裁切模板；开发过程的旧版记录不纳入公开目录。

打印：PETG、0.4 mm喷嘴、0.2 mm层高作为首样起点。主盖外表面朝床，内栅内表面朝床；内栅厚度高低差在顶面，不改变落床面。主体整件有效打印面积至少240×120 mm，不能默认用于220×220 mm平台；还须考虑裙边、夹具和机器禁区。窗片铜螺母试块用于确认孔径、目标深度、剩余壁厚和复拆保持力。

栅窗专项脚本 `scripts/v3/verify_window.py` 验证实际STL层次、无穿透、沉头避让、四耳限位、工具接近与开盖安装的离散位置。证据以当前 `generated/v3/window/verification.json` 的CAD指纹为准。强度、接触平整度及首件配合仍须实测；网页或CAD验证不代替实物验收。
