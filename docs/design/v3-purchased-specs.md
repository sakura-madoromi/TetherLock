# V3 现购物料适配版

版本：V3-purchased-specs-1。此文、当前CAD参数及重新生成的BOM优先于旧V3采购/霍尔评审。当前为人工电气台架结构样机；机械到位检测尚未实现，不能按自动闭锁整机验收。

## 已落实的变更

- 电机：按用户选定N20、3V、150rpm、M4×0.7丝杆、外伸55±1mm改模。丝杆不截短。锁栓行程仍14mm。
- 本体：卖家文字为电机16mm+齿轮箱9mm；图纸为15±0.2mm+9±0.2mm、总长24.5mm。暂以25×12×10mm保守本体包络设计，需实测复核。前视图还标有Ø3，与正文M4不一致；本版按用户选择的M4丝杆段设计，轴根形状需收货核对。
- 输出轴偏置：按图中2.5mm偏置，将电机绕轴翻转，电机本体中心高于输出轴；输出轴高仍Z38。本体底Z35.5、顶Z45.5；底垫Z35.2、压板底Z45.8。同步调整电机座、压板、螺钉及工具通道。
- 螺母：改M4法兰候选模型与捕获座，扩六角槽/法兰槽/轴孔，调整螺母盖与螺钉。盖/座右边避开闭锁位置的锁扣压板螺钉头。
- 按钮：无灯两脚无锁；用图中最大Ø17.8、后本体18.3、后端子6、面板外5.7mm。改到右侧壁，中心Y30/Z40.5；安装面X114，面板厚3mm，按钮外端X119.7，仍在240×120×55mm外包络内。旧前壁孔、背板及其两颗螺钉取消，自带螺母夹持。
- 绑带：宽2.5mm，槽宽3.0mm；托盘槽同时切通侧挡边。槽移开相邻主控固定柱；锁底座保留3mm绑带通道供后续可拆检测支架使用。
- 霍尔：三个元件、胶垫、两块磁铁、锁栓磁铁凸台/孔、盖磁铁孔、合盖霍尔座及三种霍尔试块全部退出当前装配/打印/BOM。保留GPIO3/4/5机械触点接口，当前可用按钮模拟。
- 铰链：继续使用一根连续Ø2×180mm轴，买长圆棒切断去毛刺；没有采用AB胶拼接短轴。

## 尚未确定的实物接口

1. 法兰螺母：卖家未给尺寸。候选参数为AF7、法兰Ø10、总厚5、法兰厚1mm，见`params.scad`的`nut_af/nut_flange_d/nut_height/nut_flange_t`。配套价格包含在电机里。必须实测后确认或重出座/盖，不能称为已适配实际螺母。
2. 按钮：图未标螺纹直径、有效螺纹长度、螺母外径/厚度。安装孔Ø16.4和螺母包络是候选参数；需试孔并确认3mm面板能够夹持。额外检查焊接线与弯曲空间。
3. 机械检测：微动开关SKU、固定支架、锁栓触发件、合盖触发位置未确定。本版无传感器实体、无触发可靠性结论；不能启用自动闭锁。不能把绑带槽称为已验证开关座。
4. 电气板：截图里已焊排针的ESP/DRV8833与优信TPS63020只用于台架；CAD仍保留旧候选板包络。装壳前量板、排针与出线，必要时去排针/改托盘。保护板、SM接头、去耦电容包络也仍待适配。
5. 电机：150rpm是否空载、堵转电流、低电量带载速度、自锁与轴向寿命待测。150×0.7/60=1.75mm/s，14mm理论8秒，仅为理想匀速估算，不是开锁验收。

## 验证和交付

当前19种正式打印件、6种试块，共25种STL；15种硬件包络和3组紧固件合计37组工作台模型；33处螺钉连接。

完整几何导出989项、窗栅31项、铰链/锁扣65项、附加驱动10项、储物参照33项、连续维护路径6项、现购规格14项，合计1148项通过。现购规格检查包含54/56mm轴长极限、2.5mm绑带通道、按钮端子后3mm服务空间及完整14mm连续传动扫掠。

CAD验证范围是名义刚体几何；不证明未知采购件尺寸、打印强度、触点可靠性、导线弯曲半径或带载开锁时间。完整全盖开合仍为离散角度采样；维护与传动的指定直线段另以保守Minkowski扫掠检查。
