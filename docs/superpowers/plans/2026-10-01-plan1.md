# TetherLock V3 工程工作台增强计划

## 1\. 目标、现状与约束

本次把 V3 工作台扩展成用于**采购、打印、装配和检查结构样机**的工具，完成四项已讨论的改动：

1. 去掉窗片上下缓冲垫，改为内外栅栏直接夹持亚克力。
2. 在三维预览中放入 iPhone 17 Pro Max 和银行卡，分别控制显示。
3. 补齐采购 BOM，增加详细机械蓝图、电气接线和装配信息。
4. 新增独立的“组装指导”标签页，提供步骤动画、检查清单和本机进度保存。

### 已确认的选择

| 项目 | 本次采用 |
|---|---|
| 手机参照 | 裸机，包含相机凸起，屏幕朝上 |
| 银行卡 | 放在手机屏幕上，使用虚构卡面 |
| 工程资料 | 机械蓝图＋电气接线＋完整采购 BOM |
| 组装指导 | 逐步动画＋检查清单＋进度保存 |
| 采购方向 | 优先能买到的现成模块，允许适配局部支架 |
| 工作流程 | 直接执行本计划，不启动 brainstorming |

### 当前实现基础

- 工作台使用 Vite、Three.js 和原生 JavaScript，已有“三维预览”和“工程视图”两个标签页。
- 预览加载 46 组 CAD 网格；打印文件有 29 种，其中 20 种进入正式装配，其余为试块。
- 工程视图根据当前可见网格生成三视图和等轴测，主要标注整体包络，缺少零件制造尺寸、关键剖面及完整装配信息。
- 已有 BOM 预算表，但电源板、驱动板和部分霍尔板仍采用候选包络，尚未对应完整的采购型号。
- 铰链已使用钢销和左右打印限位端盖；十处维护连接使用 M2 热熔铜螺母。
- V3 控制固件尚未完成。现有霍尔记录草图仅用于测量，不控制锁。

之前的 1,095 项整机几何检查、81 项专项检查和 19 项浏览器检查属于**修改前基线**。本次修改后重新生成证据，检查数量由实际零件和检查内容决定。

### 全局约束

- 闭合外形尽量维持 **240×120×55 mm**。
- 保留 **185×95×40 mm** 储物验收包络。
- 外栅与盖一体打印；内栅可拆；两者与外壳使用相同颜色和耗材。
- 保留 ESP32-C3、OLED、N20 丝杠机构和可取出的 18650。
- 电池取出后用独立充电器补电。
- 设备物料预算目标约 **100 元**，允许少量超出；金额标为估算，具体价格由用户后续核实。
- 独立充电器、工具、备件和外包打印费用分别列出。
- 实物开锁等待时间目标 **≤15 秒**；动画时长不作为达标证据。
- 主体继续采用整件打印。打印说明明确其打印平台需求，避免默认适用于 220×220 mm 平台。
- 本次完成工程资料和台架验收流程；控制固件作为后续独立任务。

## 2\. 数据基础与结构改版

### 2\.1 建立共用的工程数据

CAD、工程图、BOM 和组装指导共用稳定的零件编号，避免分别维护数量、规格和尺寸。

数据分成四类：

| 数据 | 内容 | 来源 |
|---|---|---|
| 几何与接口 | 坐标、尺寸、孔位、台阶、运动轴、安装关系 | OpenSCAD 参数及明确的特征元数据 |
| 零件与采购 | 数量、材质、规格、候选模块、采购备注 | 工程物料主表 |
| 图纸 | 视图、剖面、尺寸引用、零件序号、标题栏 | 几何元数据＋物料主表 |
| 组装步骤 | 所需物料、工具、动作、检查项、图纸链接 | 步骤数据，引用零件和物料编号 |

具体规则：

- 沿用现有零件 ID，不因为新增页面重新编号。
- 紧固件数量和安装位置继续从 CAD 的紧固件配置导出。
- 为各紧固位置增加稳定编号，使图纸、BOM 和组装步骤能够引用同一个连接。
- 圆孔直径、孔中心、台阶高度和名义配合值从参数读取；STL 负责投影轮廓与几何验证。
- 网格量测值与设计名义值分别标识，避免把 STL 外形测量当成孔径制造要求。
- 所有导出资料带版本号、生成日期和对应 CAD 指纹。
- 历史审查和证据保留版本归属；修改后页面只展示与当前版本对应的验证状态。

前端新增独立职责模块，分别处理尺寸参照、工程资料、BOM 和组装指导。现有入口文件负责页面协调，避免继续把所有功能堆在同一个文件中。

### 2\.2 去掉窗片缓冲垫

采用**内栅接触面加高、固定耳保持原高度**的结构：

| 部位 | 改版名义坐标 |
|---|---|
| 外栅 | Z=52～55 mm |
| 亚克力 | Z=50.5～52 mm，厚 1.5 mm |
| 内栅接触窗片的边框与栅条 | Z=47.4～50.5 mm，厚 3.1 mm |
| 内栅四个固定耳 | 保持 Z=47.4～49.9 mm，厚 2.5 mm |
| 盖内固定耳限位面 | 保持 Z=49.9 mm |
| 窗片铜螺母座 | 保持现有安装高度与名义顶面余料 |

这样消除原来两片垫材合计 0.6 mm 的空间，同时保留固定耳、螺钉及铜螺母座的基本关系。

- [ ] 删除窗片上下缓冲垫实体、装配引用、预览条目和采购行。
- [ ] 删除当前版本的窗垫裁切模板及其打包入口。
- [ ] 把内栅接触部分与固定耳高度分成独立参数。
- [ ] 保持亚克力名义尺寸 **149×82×1.5 mm**，不增加钻孔。
- [ ] 保留窗片横向装配间隙。
- [ ] 更新窗栅剖面、装配顺序、物料预算及对应试块说明。

取消垫材后，亚克力的弯曲弹性不作为夹紧补偿。四耳限位承担螺钉预紧力，窗片以直接接触方式被捕获。

试装要求明确写入图纸和指导：

- 清除接触面上的毛刺、支撑残留和明显凸点。
- 测量实际亚克力板厚。
- 四颗螺钉交叉、均匀轻拧至固定耳贴住限位面。
- 检查窗片是否晃动、翘曲或出现局部顶压。
- 若板厚或打印平整度导致不合适，通过接触高度参数调整内栅；不能靠进一步拧紧强迫窗片弯曲。

电机定位垫、PCB 胶垫和传感器定位胶垫继续按各自用途处理，不与窗片缓冲垫混删。

### 2\.3 现成模块选型与局部适配

完整采购 BOM 先解决当前“有尺寸包络、没有明确商品”的项目，再生成最终图纸。

选型顺序：

1. 确认电机的电压、丝杠规格、速度和端子包络。
2. 确认 18650、电池座和保护方案。
3. 确认主控稳压、电机驱动模块。
4. 确认三处位置检测元件及板件。
5. 确认 OLED、按键、连接器和线材。
6. 根据实际模块更新支架、压条、挡边、孔位及走线空间。

默认选择规则：

- 优先有明确尺寸、引脚说明和工作范围的现成模块。
- 每个项目确定一个用于 CAD 适配的主候选；替代型号单列。
- 候选板件必须包含最高器件、排针、接插件和出线方向的包络。
- 用局部支架适配实际模块，优先保住外形和储物包络。
- 不把芯片尺寸当作模块尺寸，不把未知板件默认塞入原来的小包络。
- 板件仅有商品照片、没有可靠尺寸时，采购状态标为“需实物确认”。

合盖霍尔候选必须支持 3.3 V，并明确输出极性、输出结构和是否锁存。现有 DRV5032ZE 候选继续保留资料记录，但是否采用取决于现成板件及其实际安装条件。

若现成模块无法满足空间、预算或合盖判定要求，输出具体冲突和相关尺寸；该项目保持可见的未解决状态，图纸不得显示为已验证装配。

## 3\. 三维参照、BOM 与工程蓝图

### 3\.1 iPhone 与银行卡参照

手机主体采用 **163\.4×78.0×8.75 mm**，相机凸起及位置根据官方配件尺寸图建模。主体厚度与包含相机的总厚度分别记录。[Apple 技术规格 (https://support.apple.com/en-la/125091)](<https://support.apple.com/en-la/125091>)、[Apple 配件尺寸图 (https://developer.apple.com/download/files/accessories/dimensional-drawings/iphone-17-pro-max.pdf)](<https://developer.apple.com/download/files/accessories/dimensional-drawings/iphone-17-pro-max.pdf>)

银行卡采用 ID-1 名义尺寸 **85\.60×53.98×0.76 mm**。[IEC 发布的卡片物理规格说明 (https://webstore.iec.ch/en/publication/11595)](<https://webstore.iec.ch/en/publication/11595>)

展示方式：

- 手机长边沿盒体 X 方向，屏幕朝上，放在储物区域中央。
- 手机最低实体点贴近储物底面，计入背面相机凸起。
- 默认采用银色机身、暗色屏幕，显示可辨认的屏幕边框、相机区和侧键。
- 银行卡平放在屏幕中央偏下位置，使用通用芯片、装饰线和虚构文字，不使用真实卡号。
- 不引入在线模型、CDN、字体或纹理依赖；外观细节在本地生成。

交互规则：

- [ ] 增加“显示手机”和“显示银行卡”两个独立开关，默认均开启。
- [ ] 保留现有储物验收块开关，默认关闭。
- [ ] 手机和银行卡固定在储物位置，不随顶盖或爆炸偏移移动。
- [ ] 两个开关分别生效；隐藏手机后，银行卡保留其既定位置。
- [ ] PNG、五视图和运动录制按当前可见状态输出参照物。
- [ ] GLB 增加“包含尺寸参照”选项，默认关闭。
- [ ] 制造蓝图、产品零件数量、设备 BOM、耗材预算均排除参照物。
- [ ] 视图配置保存两个开关；旧配置缺少字段时使用默认值。

视觉模型用于展示比例；其尺寸包络另用于检查储物空间、盖板净空及与机构的关系。

### 3\.2 完整采购 BOM

将当前混合预算表整理成三份关联清单：

1. **采购 BOM**：需要购买的零件、模块、线材和消耗品。
2. **打印清单**：正式装配打印件、数量、材质、打印文件和摆放说明。
3. **工具与备件清单**：工具、外置充电器、试块和建议备用件。

采购 BOM 每行包含：

| 字段 | 用途 |
|---|---|
| 物料编号、名称、类别 | 图纸和步骤统一引用 |
| 装机数量、采购建议数量 | 区分实际使用量与备件、整包采购 |
| 必须满足的规格 | 尺寸、电压、接口、螺纹、材质等 |
| 主候选型号或模块 | 对应本版 CAD 的适配对象 |
| 替代件条件 | 哪些属性必须一致、哪些变化需要改 CAD |
| 安装位置与关联零件 | 快速找到用途 |
| 固定方法 | 铜螺母、塑料导孔、夹持、绑带或胶粘 |
| 估算单价与装机小计 | 设备成本估算 |
| 整包采购支出 | 区分“用掉多少钱”和“实际下单多少钱” |
| 来源与核对状态 | 资料来源、包络确认、待实测项 |
| 验收方法 | 收货后具体测什么 |

必须覆盖：

- ESP32-C3、OLED、N20 丝杠电机和驱动螺母。
- 电池、电池座、电池保护、主控稳压及电机驱动。
- 三处位置检测板件、两枚磁铁、按键。
- 亚克力、钢销和十枚铜螺母。
- 所有螺钉，按规格拆行。
- 电池接头及其配对端、导线、绑带、绝缘材料、定位胶垫。
- 选定模块需要的上拉、去耦和补充元件；模块已包含时不重复计数。
- 磁铁固定所需的少量胶粘材料。
- 打印耗材，按统一材料及切片用量估算。
- 外置充电器、工具、试块、备用锁扣分别列入相应清单。

当前螺钉配置作为基线：

| 规格 | 当前数量 |
|---|---:|
| M2×6 普通头 | 14 |
| M2×8 普通头 | 5 |
| M2×4 普通头 | 2 |
| M2×6 沉头 | 8 |
| M2×8 沉头 | 4 |
| M3×8 普通头 | 2 |
| 合计 | 35 |

局部模块适配若改变紧固件，数量从 CAD 更新，页面和文档不保留旧的硬编码合计。

界面放在“工程资料”标签页内，提供：

- 分类、搜索，以及装机数量／建议采购数量切换。
- 未选定、资料已核对、待实测的状态显示。
- 点击物料查看关联零件、图纸和组装步骤。
- 设备成本、整包采购支出、工具及充电器费用分别汇总。
- 完整 CSV、仅采购 CSV、打印清单 CSV 和可打印表格导出。

去掉窗垫后，原预算分配名义减少 2 元；新的总额以模块选型结果重新计算。

### 3\.3 工程图的两种用途

“工程视图”扩展为“工程资料”，内部提供：

- **当前视图参考图**：延续现有随姿态、可见零件变化的投影功能。
- **工程蓝图集**：使用固定姿态、明确零件集合和 CAD 特征数据生成。
- **物料与打印清单**：展示采购 BOM 和打印信息。

工程蓝图不受三维预览中的隐藏、透明度、爆炸、相机和参照物开关影响。打开工程资料时默认进入蓝图集。

### 3\.5 蓝图内容要求

整机和装配图：

- 统一坐标方向、前后位置及投影约定。
- 标出装配基准、零件序号、螺钉规格和安装方向。
- 标出 14 mm 锁栓行程、105° 开盖角度及对应释放位置。
- 标出关键净空、钢销两端间隙、铜螺母深度和窗片夹持层次。
- 剖面包含实际截线、封闭截面轮廓、剖面线和剖切位置。
- 通过局部放大展示栅窗、轴套、滑块拨指和锁扣关系。
- 每张图包含图号、版本、单位、比例、页码和材料说明。

打印零件图：

- 外形、壁厚、孔位、台阶、轴孔和配合结构。
- 孔位使用基准尺寸或坐标表，避免重复尺寸相互矛盾。
- 明确区分打印预孔、装配状态让位孔、螺钉通孔及金属螺纹。
- 标出铜螺母型号、安装方向、目标深度与剩余壁厚。
- 标出正式数量、备用建议、打印摆放及支撑清理位置。
- 配合尺寸注明设计名义值与试块调整方法。

亚克力加工图：

- 标注 149×82×1.5 mm。
- 说明边缘去毛刺、边角处理和板厚测量要求。
- 导出 1:1 SVG／DXF 轮廓，并附 100 mm 比例校验线。
- 不把加工轮廓与浏览器缩放后的显示比例混为一谈。

公差说明：

- 0\.4 mm 喷嘴、0.2 mm 层高作为首样设置起点。
- PETG 作为默认材料建议；打印校准结果决定最终配合调整。
- 孔径、铜螺母预孔及运动间隙沿用试块体系核对。
- 图纸明确区分“名义尺寸”“首样目标”“待实测”。
- 未经首件测量，不把一般尺寸说明写成打印机已经能保证的公差。
- 不宣称已经通过强度、寿命、磁检测或开锁时间验证。

### 3\.6 电气资料

电源图按当前无盒内充电的方案展开：

- 18650 → 电池保护 → 主控稳压支路与电机驱动支路。
- 所有模块共地，标出电源方向、极性和模块端子名称。
- 标出电池接头两端的针序。
- 电源与电机驱动的选型条件包括电池电压范围、启动峰值及堵转能力。
- 说明开发板 USB 维护连接与电池供电之间需要核对的关系。

信号图与接线表包含：

- OLED 的电源、地和 I²C 信号。
- 按键信号与输入方式。
- 电机驱动输入及电机输出。
- 退栓、闭锁、合盖三个检测信号。
- 开漏输出所需上拉及模块已带元件的说明。
- 每条线的起点、终点、信号名、颜色约定、连接器针位和走线路径。

引脚分配在模块与 ESP32-C3 板型核对后固定，避开占用、启动和维护相关引脚。现有测量草图中的 GPIO 占位不能直接转成最终接线要求。

霍尔合盖信号继续注明：**磁铁被检测到并不自动证明锁扣对准**。电气图和组装验收明确要求测量其触发、释放与锁栓可通过范围。

### 3\.7 工程资料导出

- 单页：SVG、3840 px 工程 PNG、按真实纸张尺寸打印／保存 PDF。
- 整套：分页图纸、目录、BOM、打印清单和源指纹组成 ZIP。
- 批量导出由图纸目录驱动，冻结当前资料版本。
- 图纸采用黑白线稿，适合普通打印；屏幕阅读可使用浅色辅助高亮。
- 中文显示使用本地打包且允许嵌入的字体。
- 尺寸、线宽和纸张大小采用毫米坐标。
- 缺失元数据、未适配模块或资料版本不一致时，显示具体原因，不生成伪完整图纸。

## 4\. 独立交互式组装指导

### 4\.1 页面与状态

顶部保留三个独立标签页：

**三维预览｜工程资料｜组装指导**

组装指导布局：

- 左侧：章节、步骤列表、完成状态。
- 中间：当前步骤的三维视图和动画。
- 右侧：动作说明、物料、工具、检查项及关联蓝图。
- 底部：上一步、下一步、播放／暂停、重播、进度。

移动端改为纵向布局，步骤和说明可展开；不要求用户同时操作多个窄侧栏。

三维几何资源复用，活动页面使用一个渲染上下文。组装指导拥有独立的姿态、相机和可见零件状态；标签页切换恢复各自状态。

### 4\.2 每个步骤的数据

每步固定包含：

- 稳定步骤编号、章节和标题。
- 本步目的及具体操作顺序。
- 零件 ID、物料编号、数量和工具。
- 本步之前已安装的零件集合。
- 本步目标位置、相机和高亮零件。
- 安装路径或操作示意。
- 必须检查的项目。
- 关联图纸、打印文件或接线表。
- 人工确认后的完成状态。

动画分为：

1. **安装路径动画**：零件沿核对过的路径移动到装配位置。
2. **操作示意**：用于热装、点胶、焊接和接线，明确显示为操作说明。

螺钉旋转作为安装示意，不把画面中的转动圈数当作拧紧扭矩或真实螺纹运动。

### 4\.3 指导步骤

| 步骤 | 内容与关键检查 |
|---|---|
| 01 | 清点物料、查看尺寸核对状态；确认板件、电池座和丝杠规格 |
| 02 | 打印配合、铜螺母和霍尔试块；记录孔径与配合结果 |
| 03 | 打印正式零件；清理支撑、象脚、孔口和运动接触面 |
| 04 | 热装十枚铜螺母；检查垂直度、深度和承座变形 |
| 05 | 装驱动螺母、滑块及螺母盖；确认螺母被可靠捕获 |
| 06 | 将锁栓与滑块拨指结合，固定锁栓磁铁 |
| 07 | 安装退栓和闭锁检测板；确认元件及导线不妨碍运动 |
| 08 | 将锁模块底座固定到底壳 |
| 09 | 从顶部放入电机、丝杠、滑块与锁栓组合；检查导向关系 |
| 10 | 安装电机定位垫、压板和导向盖；手动检查全行程 |
| 11 | 在底托安装主控、电源模块及定位材料 |
| 12 | 安装上层托板、驱动模块与压条 |
| 13 | 安装 OLED 和按键；确认出线与固定 |
| 14 | 连接电源、信号和电机线束；保持电池断开，检查极性与短路 |
| 15 | 主盖外面朝下，安装亚克力和内栅；四耳到位后检查窗片 |
| 16 | 安装锁扣及其内侧压板；检查锁扣被捕获 |
| 17 | 安装合盖传感器和磁铁；测量实际安装位置 |
| 18 | 对齐主盖与底壳轴套，沿轴插入钢销 |
| 19 | 安装左右不同的销轴限位端盖；检查销轴游隙 |
| 20 | 安装电池座、接头和维护盖；确认取出路径 |
| 21 | 按台架流程检查传感信号、合盖边界和运动关系 |
| 22 | 完成首件记录，查看低电压、开合循环及 ≤15 秒开锁待测项 |

拆卸维护另设快捷章节：

- 取电池及独立充电。
- 拆内栅、更换亚克力。
- 开盖退栓后拆销轴限位端盖：先向前滑出，再向上取下。
- 拆钢销。
- 清理或更换锁驱动模块。

依赖控制固件的整机验收项目保持“待固件／待实测”状态，不能通过网页动画自动勾选完成。

### 4\.4 交互细节

- 本步零件高亮，已装零件保留，必要的遮挡件半透明。
- 提供“当前步骤”和“完整总装”视图切换。
- 用户可以旋转、缩放和聚焦；重播恢复本步默认构图。
- 提供播放、暂停和动画进度拖动。
- 任意跳转或回到前一步时，直接从步骤数据重建状态。
- 切换步骤或标签页时取消旧动画，防止后续回调改动新状态。
- 检查项由用户手动确认；完成动画不会自动确认。
- 下一步允许浏览，未完成检查保持醒目标记。
- 点击物料跳转到 BOM 对应行；点击蓝图打开对应图号。
- 支持导出本步图片及整套可打印组装说明。

### 4\.5 进度保存

- 在本机保存当前步骤、已确认检查项和完成状态。
- 提供重置及进度 JSON 导入／导出。
- 进度关联 CAD 指纹与步骤版本。
- 结构变更后保留旧记录，但提示其属于旧版；需要重新确认相关检查。
- 浏览器无法持久化时仍可使用指导，通过 JSON 保存记录。
- 组装完成状态只代表用户记录，不代表网页检测到实物已经合格。

## 5\. 实施顺序、验证与交付

### 5\.1 实施顺序

按依赖顺序完成，每阶段形成可检查的结果：

**阶段一：冻结资料与候选模块**

- [ ] 保存当前 CAD、包和证据的版本基线。
- [ ] 建立共用零件、紧固位置和物料主表。
- [ ] 核对现成模块资料，确定 CAD 适配候选及待实测项。
- [ ] 固定接线接口和采购要求。

**阶段二：修改结构**

- [ ] 完成无窗垫的阶梯内栅。
- [ ] 适配模块的支架、压条及走线空间。
- [ ] 更新打印姿态、试块和紧固件配置。
- [ ] 重新导出并验证几何，生成工程特征元数据。

**阶段三：增加尺寸参照**

- [ ] 建模手机和银行卡。
- [ ] 增加独立开关和配置兼容。
- [ ] 接入图片、五视图、录制与 GLB 的参照物规则。

**阶段四：完成工程资料**

- [ ] 完整采购 BOM、打印及工具清单。
- [ ] 蓝图目录、零件图、剖面与电气资料。
- [ ] 单页和整套导出。

**阶段五：完成组装指导**

- [ ] 编写步骤内容和检查项。
- [ ] 实现独立页面、步骤场景及安装动画。
- [ ] 接入 BOM、蓝图和打印文件链接。
- [ ] 实现进度保存与版本关联。

**阶段六：更新交付包**

- [ ] 完成验证和文档。
- [ ] 重新生成 CAD ZIP、静态工作台 ZIP、蓝图 ZIP。
- [ ] 检查下载内容与当前源码、模型、BOM 版本一致。

### 5\.2 CAD 验证

沿用现有真实 STL 几何检查，并针对本次变化补充有实际意义的场景：

- 所有正式打印件为有效封闭网格，打印姿态落床。
- 闭合包络符合 240×120×55 mm。
- 储物验收块、手机与银行卡不进入机构或盖板实体。
- 亚克力与内外栅接触关系正确，无实体穿透。
- 固定耳贴住限位面；螺钉没有顶穿、触底或压住窗片。
- 铜螺母深度、壁厚和螺钉啮合长度符合模型要求。
- 内栅可从盒内拆装，工具能接近四颗螺钉。
- 新模块、排针、连接器及走线包络不妨碍机构。
- 铰链、端盖拆卸、钢销抽出和锁栓运动继续通过检查。
- 组装动画对应的真实安装路径检查扫掠包络。

按顺序运行现有 CAD 导出、栅窗、铰链／霍尔和附加驱动验证，再生成渲染及包；避免导出删除中间文件时同时渲染。

### 5\.3 数据与蓝图验证

- BOM 装机数量与 CAD 硬件、螺钉和打印清单对应。
- 零件、图号、步骤和物料编号引用均有效。
- 参照物、试块、工具及外置充电器没有误计入装机数量。
- 同一尺寸在模型元数据和图纸中一致。
- 亚克力 SVG／DXF 尺寸与比例校验线正确。
- 剖面轮廓闭合，剖面线不越过实体边界。
- 图纸标题栏、字体、比例和页码完整。
- BOM 续页不切断表格行，表头重复。
- 修改预览姿态、隐藏件或关闭手机后，标准蓝图保持相同制造尺寸。
- 未核对模块和待实测项目在页面与导出中保持可见。

### 5\.4 浏览器与交互验证

- 三个标签页可正常进入并恢复各自状态。
- 手机与银行卡默认显示，可分别关闭。
- 参照物不随顶盖运动、爆炸位移或零件隔离意外改变位置。
- 导出图片和录制遵循可见状态，工程蓝图遵循固定资料状态。
- BOM 搜索、分类、链接和 CSV 下载正确。
- 步骤跳转、倒退、动画暂停、重播和拖动结果稳定。
- 快速切换步骤和标签页不留下动画回调或错误姿态。
- 刷新后恢复本机进度；旧版本、损坏 JSON 和不可用存储不会导致页面失效。
- 三维图片、工程图和组装图的导出相互独立。
- 桌面和约 390 px 移动端布局可使用。
- 静态包通过 HTTP 离线使用，无外部资源请求。
- 保留现有选件、测距、联锁、剖切、PNG、GLB、视图 ZIP 和 WebM 功能的回归检查。

### 5\.5 实物验收记录

随包提供记录表，明确这些需要采购及打印后的测量：

- 亚克力厚度、夹持状态和窗片晃动。
- 铜螺母保持力、承座变形和复拆情况。
- 销轴孔径、端盖固定及铰链手感。
- 锁栓手动全行程与首次对准阻滞边界。
- 霍尔的触发、释放及合盖误判范围。
- 实际模块尺寸、线束避让和接头极性。
- 电源瞬态、低电压和电机带载表现。
- 控制固件就绪后的开合循环及 ≤15 秒开锁时间。

记录表初始为空，不写入模拟实测数据。
