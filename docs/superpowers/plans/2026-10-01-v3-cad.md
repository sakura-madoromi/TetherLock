# TetherLock V3 CAD Implementation Plan

> **For agentic workers:** Execute inline in the authorized workspace. Checkpoints below replace a separate execution handoff because the user explicitly requested CAD generation. No commit, branch mutation or publication is requested.

**Goal:** Deliver an inspectable V3 structural CAD prototype, printable part exports, complete provisional hardware envelopes, and reproducible geometry checks.

**Architecture:** New independent `cad/v3/` subtree. Offset M3 screw moves a nut carriage whose finger engages a laterally floating fork on a solid bolt. A keyed guide supports the bolt independently. An isolated battery compartment opens underneath the main lock box.

**Tech Stack:** OpenSCAD CLI, Python standard library, SVG/PNG previews.

**Spec:** `docs/design/v3-proposal.md`, current design baseline; unresolved acceptance items are tracked in `docs/design/v3-purchased-specs.md`.

## Global Constraints

- Closed overall envelope 240×120×55 mm including hinge.
- Target object envelope 185×95×40 mm and removal path.
- No external USB or internal charger; removable 18650 and separate charger.
- Unlock confirmation ≤15 seconds is a physical acceptance requirement, not proven by CAD.
- Approximately RMB 100 with a small overrun allowed; procurement prices checked later by user.
- Hardware that has no frozen SKU must be labelled provisional; no strength or manufacture-release claim.
- V3 is the only maintained CAD and export baseline; old version sources and exports are not part of the current tree.

## File boundaries

- `cad/v3/params.scad`: shared dimensions and assembly interfaces.
- `cad/v3/enclosure.scad`: shell, lid, battery cover, latch, retainers.
- `cad/v3/lock.scad`: module base, guide, solid bolt, floating drive, motor clamp.
- `cad/v3/electronics.scad`: removable electronics carrier and retainers.
- `cad/v3/hardware.scad`: provisional purchased part envelopes and fasteners.
- `cad/v3/assembly.scad`: part dispatch, assembled/open/exploded and printable views.
- `scripts/v3/export_verify.py`: fresh exports, topology, pairwise interference, motion, storage and negative controls.
- `docs/design/v3-cad.md`, `v3-bom.csv`: dimensions, assembly, print placement and unresolved hardware/physical checks.
