# V3 Preview Workbench Implementation Plan

User explicitly requested direct implementation without brainstorming. Execute inline in the authorized workspace; no commit or publication. Existing historical HTML and V3 CAD remain intact.

**Goal:** A polished local Vite workbench using actual verified V3 geometry, with reliable motion and reusable preview/engineering exports.
