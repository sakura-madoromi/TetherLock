## 二、 MG90S 舵机固定与 M2 六角螺母沉槽深度验算

```
       [ 2x M2×12mm 内六角圆柱头螺钉 ] (从正上方垂直拧入)
               |                 |
               v                 v
       +---------------+ +---------------+
       |  MG90S 左固定耳 | |  MG90S 右固定耳 |  <--- 耳厚 2.5mm, 承压面 Z=23.4mm
       +---------------+ +---------------+
               |                 |
       ========+                 +========
       | (o)                         (o) |  <--- 3D 打印立柱 (承托面 Z=20.9mm)
       |                                 |
       | [==== M2 金属六角螺母 ====]      |  <--- 侧向插槽 (Z=13.5~15.5mm, 厚2.0mm)
       +---------------------------------+
```

### 1. 螺栓长度匹配计算
* 舵机耳朵承托面高：$Z = 20.90\text{mm}$
* 舵机耳朵厚度：$2.50\text{mm}$ $\rightarrow$ 螺钉承压沉头面高度：$Z = 23.40\text{mm}$
* M2 螺母沉槽标高：$Z = 13.50 \sim 15.50\text{mm}$（槽中心 $Z=14.50\text{mm}$）
* **穿透深度要求**：
  * 穿至螺母顶面深度：$23.40 - 15.30 = 8.10\text{mm}$
  * 穿透螺母底面深度：$23.40 - 13.70 = 9.70\text{mm}$
* **选型结果**：
  * **选用 M2×10mm 螺栓**：穿入深度 $10.00\text{mm}$，咬合螺母螺纹 $1.90\text{mm}$，螺母吃满率达 $100\%$；
  * **选用 M2×12mm 螺栓（最推荐）**：穿入深度 $12.00\text{mm}$，螺栓完全穿透螺母并探出 $2.3\text{mm}$ 引导尖，手感极佳。

### 2. 沉槽装配间隙与防转
* DIN 934 M2 六角螺母对边宽度：$S = 4.00\text{mm}$，厚度 $m = 1.60\text{mm}$；
* 3D 打印预留槽尺寸：宽 $4.20\text{mm}$，高 $2.00\text{mm}$，深度 $11.0\text{mm}$；
* **间隙分析**：宽度单边留隙 $+0.10\text{mm}$，FDM 打印收缩后螺母轻松推进，左右两壁卡死六角面，**防转角隙 $< 1.8^\circ$**；高度留隙 $+0.40\text{mm}$，提供极佳的轴向引线容差。

## 三、 ESP32-C3 SuperMini 硬件托架与 Type-C 端口防撞审查

### 1. Type-C 端口插拔深度
* 箱体外壁位置：$X = 120.00\text{mm}$，内壁位置：$X = 117.60\text{mm}$（壁厚 $2.40\text{mm}$）；
* SuperMini PCB 坐落于托架：$X \in [94.75, 117.25]\text{mm}$；
* Type-C 母座前金属唇伸出 PCB 边缘 $1.20\text{mm}$ $\rightarrow$ 金属唇位于 $X = 118.45\text{mm}$；
* **母座相对于外壳外表面凹陷深度**：$120.00 - 118.45 = \mathbf{1.55\text{mm}}$；
* **有效插入深度验证**：
  * USB-IF 官方标准 USB-C 公头金属外露长度：$\ge 6.50\text{mm}$；
  * 扣除外壁 $1.55\text{mm}$ 凹陷后，金属公头插入母座内部深度为：$6.50 - 1.55 = \mathbf{4.95\text{mm}}$；
  * 行业标准 Type-C 母座弹片触点完全导通深度：$4.60 \sim 4.90\text{mm}$；
  * $\mathbf{4.95\text{mm} > 4.90\text{mm}}$，**完全进入可靠锁止卡位，供电与串口下载 100% 导通**！

### 2. 防外部线缆粗塑料胶壳干涉（喇叭沉台设计）
* 现实中很多快充编织线或粗插头的塑料保护套（Collar）外径达 $11.5 \sim 12.0\text{mm}$；
* 在最新 CAD 中，外壁插口除保留 $9.0 \times 3.8\text{mm}$ 金属通孔外，外表面增设了 **深 $1.2\text{mm} \times$ 宽 $12.4\text{mm} \times$ 高 $6.2\text{mm}$ 的倒角沉头槽**；
* 哪怕使用特厚外壳的第三方数据线，其胶套前端也会自然下沉进入沉台，彻底消除“线壳顶住塑料箱子导致插不紧”的隐患。

### 3. PCB 底部引脚与元器件净空
* 托架将主板支承在标高 $Z = 12.0\text{mm}$；
* 箱体底板内表面位于 $Z = 2.4\text{mm}$ $\rightarrow$ **主板下方拥有高达 $9.60\text{mm}$ 的垂直悬空安全净空**；
* 托架底部开有 $14.0 \times 12.0\text{mm}$ 的散热通孔，即使主板正面或反面焊接了长引脚排针，也绝不会顶到箱底或发生短路。

* 弧形托架实心段长度：$63.00\text{mm}$；
* 标准平头 18650 电芯长度：$65.00\text{mm}$；
* **轴向富余空间**：$69.10 - 65.00 = \mathbf{4.10\text{mm}}$：
  * **推荐方案（点焊引线电芯）**：选用淘宝成品带线 18650 电池（已点焊好正负极红黑引线），两端仅需 $0.5\text{mm}$ 间隙，前后富余 $3.6\text{mm}$ 供引线顺畅拐弯通往前仓；

### 2. 径向抱爪（C-Claw Snaps）配合

### 3. 锁孔标高重合核验
