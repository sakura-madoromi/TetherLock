## 📖 项目愿景与设计哲学

在自律与防沉迷产品（锁机盒、时间锁）泛滥的今天，绝大多数现有方案面临两个极端困境：
1. **纯机械/廉价厨房定时锁**：抠掉电池即可重置、结构脆弱易无痕撬动，自律崩溃时防线形同虚设；
2. **厚重铁皮保险箱**：冰冷笨重、毫无社交情感温度，只能按固定死板倒计时运行。

**TetherLock（牵绊锁盒）** 提出了全新的设计哲学 —— **以信任与羁绊为核心，将开锁权限交由远方你在乎的人**：
* 📱 **远程陪伴与权限托管**：被锁者无法自行解开；远方的伴侣/挚友通过手机 App 远程掌控倒计时、随时查看开锁请求、并留下一句充满鼓励的悄悄话；
* 📺 **0.96" OLED 像素情感交互**：实时呈现对方发送的问候、调侃表情包与倒计时流逝；
* ⚡ **零服务器运维门槛**：去中心化架构，通过任意公共或自建 MQTT Broker 进行透传，配合 **Ed25519 非对称公私钥签名**，端到端防篡改、防重放；
* 💔 **可控易损牺牲件（Breakaway Latch）**：拒绝无痕作弊。若遇到不可抗力或意志力彻底崩溃，双手暴力拉开盒盖即可齐整折断预制颈部脱困，**保护盒体结构与电气主板毫发无损**。但破戒即留痕，换上新锁舌仅需 1 秒（0 螺丝、0 胶水）。

### 1. 易损牺牲锁舌与精密燕尾滑轨 (Breakaway Latch)
* **燕尾滑动配合**：公母燕尾榫宽 $8.0\text{mm} \times 4.0\text{mm}$，拔模角 $60^\circ$。单侧预留 $0.2\text{mm}$ FDM 打印补偿间隙，滑动顺滑且垂直无晃动；
* **力学断裂槽**：在锁舌受拉过渡段预制 $1.0\text{mm} \times 8.0\text{mm}$ 的 V 型刻痕。日常状态下可承受 **5 ~ 8 kg** 的垂直拉力；紧急强拆状态下（拉力 > 12 kg），锁舌沿刻痕脆断，箱体与铰链完全不受损；
* **秒级复活**：开盒后将残端推出丢弃，直接从滑轨推入新打印的备用锁舌即可。

### 2. M2 内六角螺栓 + 底盒自锁螺母沉槽 (DIN 912 + DIN 934)
* 舵机直接承受动态闭锁扭矩与可能的撬动力，彻底摒弃不牢固的胶水或热熔螺母工艺；
* 底盒安装柱预留向 $+Y$ 开口的横向内嵌六角螺母槽（槽宽 $4.2\text{mm}$，厚度 $2.0\text{mm}$），配合标准 M2 六角螺母实现高精度自防转（防转余量 $< 1.8^\circ$）；
* 从舵机耳座上方旋入标准 **M2 × 12mm 杯头螺栓**，实现工业级刚性紧固。

### 3. Type-C 端口防撞沉台 (Collar Relief Pocket)
* 针对市面上各类加粗编制数据线外壳（宽 $11.5 \sim 12.0\text{mm}$），底盒侧壁特设 $12.4\text{mm} \times 6.2\text{mm}$、深 $1.2\text{mm}$ 的防撞倒角沉台；
* 消除插头胶壳与外壳干涉，保证标准 $6.5\text{mm}$ Type-C 插头能够达到 $4.95\text{mm}$ 的有效金属接触深度，确保应急供电万无一失。

### 4. 铠甲透光天窗 (Armored Skylight Window)
* 顶盖上表面预留 $120\text{mm} \times 70\text{mm}$ 的内嵌亚克力卡槽，支持装配 $2.0\text{mm}$ 高透光耐磨亚克力板；
* 兼具“清晰看见盒内受控物品（强化自律期待感）”与“防止异物伸入拨动内部锁舌”的双重功能。

## 🖨️ 3D 打印指南

所有模型均经过水密性（Manifold）与切片无悬空优化，**在推荐放置姿态下可实现 100% 免支撑（0-Support）打印**：

| 部件名称 | STL 文件路径 | 推荐打印姿态 | 建议壁厚/填充 | 耗材材质 | 支撑需求 |
| :--- | :--- | :--- | :--- | :---: | :---: |
| **主箱体** | [`cad/base_box.stl`](cad/base_box.stl) | 箱底贴热床，Z 轴朝上 | 4层壁厚 / 20% 陀螺填充 (Gyroid) | PETG / PLA+ | **无需支撑** |
| **天窗顶盖** | [`cad/top_lid.stl`](cad/top_lid.stl) | 顶面贴热床朝下，水平平放 | 4层壁厚 / 25% 网格填充 | PETG / PLA+ | **无需支撑** |
| **易损锁舌** | [`cad/breakaway_latch.stl`](cad/breakaway_latch.stl) | 侧面平放（使拉力平行于线材纤维） | 100% 实体填充 | **标准 PLA** | **无需支撑** |
| **舵机凸轮** | [`cad/servo_cam.stl`](cad/servo_cam.stl) | 圆轴套大端面贴热床 | 100% 实体填充 | PLA+ / ABS | **无需支撑** |
| **舵机压板** | [`cad/servo_clamp.stl`](cad/servo_clamp.stl) | 大平底贴热床 | 100% 实体填充 | PLA+ / PETG | **无需支撑** |

> [!TIP]
> * **易损锁舌材质提示**：**请务必使用普通 PLA 打印**。普通 PLA 具有理想的脆性断裂力学特性，在极端过载撬动时能沿 V 型折断槽整齐断开；切勿使用 TPU、尼龙或高延展性 PC 材质。
> * **切片层高建议**：主箱体与顶盖建议采用 `0.20mm` 层高；锁舌与舵机凸轮建议采用 `0.16mm` 层高以确保燕尾滑动表面光洁度。

## 🛠️ 装配指引

1. **螺母与五金预埋**：
   * 将 2 颗 M2 六角螺母沿 $+Y$ 方向滑入底盒舵机安装柱底部的六角沉槽中；
2. **舵机校准与紧固**：
   * 用测试固件将 MG90S 舵机打到 $0^\circ$（锁定初始位）；
   * 将舵机放入底盒卡座，盖上自锁压板，从上方穿入 2 颗 M2×12mm 杯头螺栓，旋紧至螺母受拉锁死；
   * 将 [`servo_cam.stl`](cad/servo_cam.stl) 锁舌凸轮垂直对准花键压入舵机轴，拧入舵机自带中心自攻螺钉固定；
3. **主控与电气接线**：
   * 将 ESP32-C3 SuperMini 卡入右侧限位卡槽，确保 Type-C 接口对齐外壳沉台口；
   * 焊接 I2C 四线至 0.96" OLED，将屏幕涂抹少量环氧 AB 胶贴合在 15° 视窗内侧；
   * 串接 AO3401 P-MOS 管至舵机红线供电回路，消除休眠待机漏电；
4. **顶盖与轴销结合**：
   * 裁切 $120 \times 70 \times 2.0\text{mm}$ 透明亚克力板，从侧向滑入顶盖天窗夹层卡槽；
   * 对齐箱体后置铰链孔，插入 $\phi 2.0\text{mm}$ 不锈钢轴销（或一段平直的自行车辐条/回形针钢丝）；
5. **装入易损锁舌**：
   * 将打印好的 [`breakaway_latch.stl`](cad/breakaway_latch.stl) 从顶盖前内侧燕尾槽滑入到底即可。

## 🔐 密码学安全与 MQTT 协议

系统彻底舍弃中心化云后台，基于现代密码学标准构建**去中心化端到端信任链**：

```
[Flutter App 掌管端]                               [ESP32-C3 锁盒端]
(内嵌 Ed25519 秘钥)                                (固件预留信任公钥白名单)
        |                                                   |
        +-- (1) 用户设定倒计时 / 留言 / 点击放行 ------------+
        |                                                   |
        +-- (2) 生成规范报文: "box_01|nonce|unlock|留言" ----+
        |                                                   |
        +-- (3) Ed25519 私钥签名生成 64 字节签名 (Base64) ---+
        |                                                   |
        +-- (4) 发布至 MQTT 保留消息 (Retain = true) ------->|
                                                            |
                                                    (5) ESP32 定时唤醒拉取
                                                            |
                                                    (6) 检查 Nonce > 本地计数器
                                                            |
                                                    (7) 校验 Ed25519 签名
                                                            |
                                                    [ 验签通过: PMOS 上电开锁 ]
                                                            |
                                                    (8) 发布空报文清除 Retain
                                                            |
                                                    (9) 累加保存 Nonce -> 休眠
```

### 电源账本与续航实测
* **深度睡眠电流**：ESP32-C3 RTC 待机 $\approx 15\mu\text{A}$，舵机经 PMOS 物理断电 $0\mu\text{A}$；
* **定时静默轮询**：每 60 秒自动唤醒 1.2 秒连接 Wi-Fi 与 MQTT（屏幕不亮、不发声），单次消耗约 $0.0416\text{ mAh}$；
* **续航能力**：单节 2600mAh 18650 电池可支持 **超过 35 天** 的不间断稳定守护。
