# V3 生成资料

本目录保存 V3 的验证输出、评审证据和交付包。内容由 `scripts/v3/` 生成，源文件位于 `cad/v3/`、`stl/v3/` 和 `scripts/`。

- `TetherLock-V3-CAD.zip`：CAD、分件和验证脚本交付包。
- `TetherLock-V3-Blueprints.zip`：图纸和工程资料交付包。
- `TetherLock-V3-Workbench.zip`：可直接用浏览器打开的静态工作台。

这些资料只证明部分名义几何和数字检查结果。它们不替代实物试装、强度与耐久测试、电气验证、固件验证或安全验收；项目仍处于未完工状态。

开发过程中的修改前快照不纳入公开目录；当前维护基线以源文件、当前验证结果和上面的三个交付包为准。

重新生成前请阅读根目录 [README](../../README.md) 和 [V3 工作台说明](../../docs/design/v3-viewer.md)。
